## Objetivos

Programação de microcontroladores. Estudo dos principais 
tópicos acerca de programação para microcontroladores e sistemas embarcados 
(temporizadores, interrupções, comunicação serial síncrona e assíncrona, conversão A/D). 
Desenvolver soluções para problemas do dia a dia utilizando microcontroladores.

## Ementa Resumida
- Arquitetura MSP430.
- Conjunto de instruções e programação assembly.
- Entradas e saídas (GPIO).
- Programação em C.
- Interrupções.
- Configuração do relógio.
- Comunicação serial.
- Conversor A/D com DMA.
